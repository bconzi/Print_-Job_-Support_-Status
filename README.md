# Print Job Support Monitor

## Project Overview

A small PowerShell and SQL Server project designed to help IT support staff retrieve print job information for a specific customer.

## Technologies
- PowerShell
- SQL Server
- T-SQL

## Project Goals

- Connect PowerShell to SQL Server.
- Retrieve customer and print job information.
- Use SQL JOINs to combine related tables.
- Filter results by customer ID.
- Display relevant job information in PowerShell.

## Development Notes

ChatGPT was used as a learning assistant to help generate fictional database records, understand the SQL Server connection from PowerShell, and clarify how both technologies interact.

The SQL query logic and data structure were designed and developed by me, with the goal of understanding each step rather than simply copying a solution.
